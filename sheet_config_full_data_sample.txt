PHẦN 1: FILE MÃ NGUỒN VÀ HÀM CHỊU TRÁCH NHIỆM GHI DỮ LIỆU
================================================================================

File mã nguồn thực hiện toàn bộ việc ghi và cập nhật vào tab `__CONFIG__` là:
👉 Đường dẫn: `src/utils/googleDriveService.ts`

Trong đó có 2 hàm cốt lõi:
1. `saveMasterSyncStateToGoogleSheet(accessToken, fileId, state)` (Dòng ~2269):
   - Chịu trách nhiệm trực tiếp tương tác với Google Sheets API v4.
   - Chuẩn bị ma trận 11 hàng x 2 cột (Dải ô `__CONFIG__!A1:B11`).
   - Gọi endpoint `POST https://sheets.googleapis.com/v4/spreadsheets/{fileId}/values:batchUpdate`.
   - Nếu tab `__CONFIG__` chưa tồn tại trong Google Sheet, hàm tự động phát hiện (HTTP 400) và tạo mới tab ẩn này thông qua `addSheet` request trước khi ghi dữ liệu.

2. `saveMasterSyncStateOnDrive(accessToken, state)` (Dòng ~2458):
   - Hàm điều phối cấp cao.
   - Vừa đồng bộ lưu trạng thái cục bộ vào `localStorage` (để app khởi động tức thì trong 0ms), vừa gọi `saveMasterSyncStateToGoogleSheet` để ghi lên Google Drive.
   - Đồng thời tự động kích hoạt hàm kiểm toán quyền `synchronizeDrivePermissionsWithJsonMembers(...)` để đối chiếu phân quyền trên Drive khớp 100% với danh sách thành viên.

* Các luồng nghiệp vụ gọi hàm này:
  - Khi Admin tạo file mới: `createRealGoogleDriveFile`
  - Khi Admin liên kết file: `setMasterSyncLinked`
  - Khi Admin hủy liên kết file: `setMasterSyncUnlinked`
  - Khi Admin thêm / đổi vai trò / xóa thành viên: `updateMemberRoleOnDrive`, `removeMemberFromDriveMaster`
  - Sau mỗi lần đồng bộ 2 chiều thành công: `pushBooksToDrive` (trong `src/hooks/useDriveSync.ts`)

================================================================================
PHẦN 2: CẤU TRÚC BẢNG DỮ LIỆU CỦA TAB __CONFIG__ (DẢI Ô A1:B11)
================================================================================

Tab `__CONFIG__` được thiết kế dưới dạng bảng cặp Khóa - Giá trị (Key-Value) gồm 2 cột:
- Cột A: Tên khóa (Key)
- Cột B: Giá trị (Value - Chuỗi văn bản thông thường hoặc chuỗi JSON đối tượng)

Bảng phân bổ dải ô:
+-----+----------------------+-------------------------------------------------+
| Hàng| Cột A (Key)          | Cột B (Value)                                   |
+-----+----------------------+-------------------------------------------------+
| 1   | __METADATA_JSON__    | JSON tóm tắt siêu dữ liệu hệ thống (Core Meta)  |
| 2   | Vault Name           | Tên hiển thị của kho dữ liệu / bảng tính        |
| 3   | Admin Email          | Email của Quản trị viên (Chủ không gian)        |
| 4   | Linked Account       | Email tài khoản Google đã thực hiện liên kết    |
| 5   | Status               | Trạng thái hoạt động: "active" hoặc "unlinked"  |
| 6   | Last Action          | Hành động cuối: link / switch / unlink          |
| 7   | Linked Timestamp     | Ngày giờ liên kết định dạng chuẩn Việt Nam      |
| 8   | Updated At           | Ngày giờ cập nhật gần nhất định dạng Việt Nam   |
| 9   | Members JSON         | JSON mảng toàn bộ thành viên và quyền hạn       |
| 10  | Banks Config         | JSON mảng cấu hình danh sách ngân hàng          |
| 11  | Audit Logs JSON      | JSON mảng 15 bản ghi kiểm toán gần nhất         |
+-----+----------------------+-------------------------------------------------+

PHẦN 4: NGUYÊN LÝ GIỚI HẠN VÀ TỐI ƯU HÓA TRÁNH LỖI GOOGLE SHEETS
================================================================================

Trong thực tế, Google Sheets có giới hạn kỹ thuật:
- **Giới hạn ô**: 1 ô của Google Sheet không thể chứa chuỗi văn bản dài quá 50,000 ký tự (Cell character limit: 50,000 chars).
- Nếu ghi một mảng log quá lớn hoặc chi tiết từng cuốn sổ vào ô B11 (`Audit Logs JSON`), request sẽ bị Google từ chối với lỗi HTTP 400 Bad Request.

Giải pháp tối ưu đã được cài đặt trong `src/utils/googleDriveService.ts`:
1. **Lọc gọn nhẹ Audit Logs**:
   - Chỉ giữ tối đa 15 bản ghi log gần nhất (`effectiveAuditLogs.slice(0, 15)`).
   - Tự động bóc tách và loại bỏ các mảng danh sách chi tiết cồng kềnh như `columns_A_to_M_books`, `columns_U_to_AC_settlements`, `columns_N_to_P_annualInterest`, `columns_Q_to_S_balanceGrowth` trước khi nén JSON lưu vào ô B11.
2. **Kiểm tra MimeType**:
   - Nếu tệp đang liên kết là file Excel nhị phân (`.xlsx`) thay vì Google Sheets nguyên bản, hàm sẽ tự động bỏ qua ghi tab `__CONFIG__` bằng Sheets API để tránh lỗi không tương thích.

PHẦN 5: ĐOẠN CODE GHI DỮ LIỆU THỰC TẾ TRONG DỰ ÁN
================================================================================

Trích đoạn mã nguồn thực tế tại `src/utils/googleDriveService.ts`:

```typescript
export async function saveMasterSyncStateToGoogleSheet(
  accessToken: string,
  fileId: string,
  state: MasterSyncState
): Promise<boolean> {
  try {
    if (!accessToken || !fileId) return false;

    const effectiveBanksConfig =
      Array.isArray(state.banksConfig) && state.banksConfig.length > 0
        ? state.banksConfig
        : getAllBanks();

    const effectiveAuditLogs =
      Array.isArray(state.auditLogs) && state.auditLogs.length > 0
        ? state.auditLogs
        : getSyncAuditLogs();

    // Rút gọn Audit Logs tránh vượt quá giới hạn 50,000 ký tự của một ô trong Sheets
    const lightweightAuditLogs = effectiveAuditLogs.slice(0, 15).map((log) => {
      if (log.details) {
        const {
          columns_A_to_M_books,
          columns_U_to_AC_settlements,
          columns_N_to_P_annualInterest,
          columns_Q_to_S_balanceGrowth,
          ...restDetails
        } = log.details;
        return {
          ...log,
          details: restDetails,
        };
      }
      return log;
    });

    const nowIso = state.updatedAt || new Date().toISOString();
    const nowVi = state.updatedAtVi || formatIsoToVietnamTime(nowIso);
    const coreMetadataPayload = JSON.stringify({
      schemaVersion: 2,
      status: state.status || 'active',
      lastAction: state.lastAction || 'link',
      activeFileId: state.activeFileId || fileId,
      activeFileName: state.activeFileName || '',
      activeFileUrl: state.activeFileUrl || `https://docs.google.com/spreadsheets/d/${fileId}/edit`,
      adminEmail: state.adminEmail || '',
      linkedAccountEmail: state.linkedAccountEmail || '',
      linkedTimestamp: state.linkedTimestamp || '',
      linkedLocalTimeVi: state.linkedLocalTimeVi || '',
      updatedAt: nowIso,
      updatedAtVi: nowVi,
    });

    const values: (string | number)[][] = [
      ['__METADATA_JSON__', coreMetadataPayload],
      ['Vault Name', state.activeFileName || ''],
      ['Admin Email', state.adminEmail || ''],
      ['Linked Account', state.linkedAccountEmail || ''],
      ['Status', state.status || 'active'],
      ['Last Action', state.lastAction || 'link'],
      ['Linked Timestamp', state.linkedLocalTimeVi || state.linkedTimestamp || ''],
      ['Updated At', nowVi],
      ['Members JSON', JSON.stringify(state.members || [])],
      ['Banks Config', JSON.stringify(effectiveBanksConfig)],
      ['Audit Logs JSON', JSON.stringify(lightweightAuditLogs)],
    ];

    // Kiểm tra mimeType file
    const metaCheck = await getRealGoogleDriveFileMetadata(accessToken, fileId);
    if (metaCheck?.mimeType && metaCheck.mimeType !== 'application/vnd.google-apps.spreadsheet') {
      return true;
    }

    const batchUrl = `https://sheets.googleapis.com/v4/spreadsheets/${fileId}/values:batchUpdate`;
    const writeData = () => fetchWithRetry(batchUrl, {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${accessToken}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        valueInputOption: 'USER_ENTERED',
        data: [
          {
            range: `__CONFIG__!A1:B${values.length}`,
            majorDimension: 'ROWS',
            values: values,
          }
        ]
      }),
    });

    let updateRes = await writeData();

    // Nếu tab __CONFIG__ chưa tồn tại (HTTP 400), tự động tạo tab mới rồi thử ghi lại
    if (!updateRes.ok && updateRes.status === 400) {
      const createRes = await fetchWithRetry(`https://sheets.googleapis.com/v4/spreadsheets/${fileId}:batchUpdate`, {
        method: 'POST',
        headers: {
          Authorization: `Bearer ${accessToken}`,
          'Content-Type': 'application/json',
        },
        body: JSON.stringify({
          requests: [
            {
              addSheet: {
                properties: {
                  title: '__CONFIG__',
                  hidden: false,
                  gridProperties: { rowCount: 50, columnCount: 5 }
                }
              }
            }
          ]
        }),
      });

      if (createRes.ok) {
        updateRes = await writeData();
      }
    }

    return true;
  } catch (err: any) {
    console.warn('[Sheet Config] Lỗi hệ thống khi ghi tab cấu hình:', err);
    return false;
  }
}
```
