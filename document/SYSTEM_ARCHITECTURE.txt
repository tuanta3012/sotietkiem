PHẦN 1: TỔNG QUAN DỰ ÁN & TECH STACK
--------------------------------------------------------------------------------

1.1. Công nghệ cốt lõi (Core Tech Stack)
* Frontend Framework: React 19 (Functional Components, Custom Hooks)
* Build Tooling & Bundler: Vite 6 (ESM, Fast HMR, Rollup optimized build)
* Ngôn ngữ: TypeScript 5.8 (Strict type checking, Interface-driven design)
* Giao diện & Styling: Tailwind CSS v4 (@import "tailwindcss", Material 3 mobile UI)
* Bộ icon: Lucide React (vector icon siêu nhẹ, tối ưu hóa bundle)
* Native Mobile Bridge: Capacitor JS v6 (@capacitor/core, @capacitor/android)
* Bảo mật & Mã hóa thiết bị: capacitor-secure-storage-plugin (Android KeyStore hardware-backed)
* Sinh trắc học: @capgo/capacitor-native-biometric (Vân tay / Face ID / Mã PIN máy)
* Xác thực Google: @codetrix-studio/capacitor-google-auth (Native Google Play Services SDK)
* Cơ sở dữ liệu đám mây: Firebase v12 (Cloud Firestore, HTTP Long-Polling)
* Lưu trữ đám mây: Google Drive v3 REST API & Google Sheets v4 REST API
* Xử lý bảng tính: SheetJS (xlsx) xử lý đọc/ghi file Excel nhị phân trực tiếp trên client
* CI/CD & Auto Release: GitHub Actions (Ubuntu runner, JDK 21, Gradle, Auto Tag & GitHub Releases)

1.2. Kiến trúc phân tầng (Layered Architecture)
Hệ thống được thiết kế theo mô hình 4 tầng tách biệt hoàn toàn:
  ┌────────────────────────────────────────────────────────────────────────┐
  │ 1. PRESENTATION LAYER (Giao diện người dùng - React Components)        │
  │    - Views: BookListView, InterestCalculationView, MobilizationOpt...  │
  │    - Modals: LoginModal, AppUpdateModal, BiometricUnlockModal...       │
  │    - Atoms: DatePickerVN, BankSelectDropdown, CustomSelect...          │
  └───────────────────────────────────┬────────────────────────────────────┘
                                      │
  ┌───────────────────────────────────▼────────────────────────────────────┐
  │ 2. HOOKS & CONTROLLER LAYER (Quản lý nghiệp vụ & State Management)     │
  │    - useSavingsBooks: Quản lý danh sách sổ, tính toán, bộ lọc, CRUD    │
  │    - useDriveSync: Điều phối đồng bộ 2 chiều Google Drive / Sheets     │
  │    - ToastContext: Hệ thống thông báo toast toàn cục                   │
  └───────────────────────────────────┬────────────────────────────────────┘
                                      │
  ┌───────────────────────────────────▼────────────────────────────────────┐
  │ 3. SERVICE / INTEGRATION LAYER (Dịch vụ & Giao tiếp ngoài)             │
  │    - googleDriveService: OAuth, Token Refresh ngầm, Drive/Sheets API   │
  │    - firebaseFirestoreService: Real-time Master Pointer, Sync Audit Log│
  │    - secureStorage: Đọc/ghi KeyStore, Preferences, LocalStorage        │
  │    - notificationService: Lập lịch thông báo native nhắc đáo hạn sổ    │
  │    - excelParser & dataTranslator: Chuyển đổi định dạng dữ liệu        │
  │    - calculator & formatters: Công thức tài chính, định dạng tiền VNĐ  │
  └───────────────────────────────────┬────────────────────────────────────┘
                                      │
  ┌───────────────────────────────────▼────────────────────────────────────┐
  │ 4. STORAGE & NATIVE DEVICE LAYER (Phần cứng & Lưu trữ)                 │
  │    - Android Keystore Hardware / SharedPreferences / WebView Storage   │
  │    - Google Drive Cloud / Firebase Cloud Firestore                     │
  └────────────────────────────────────────────────────────────────────────┘

1. Service: Google OAuth & Google Drive / Sheets REST Engine
   - Tên file: src/utils/googleDriveService.ts

     * Gọi Google Drive API v3 (Search, Upload multipart/form-data, Download, Metadata).
     * Gọi Google Sheets API v4 (Read matrix values, BatchUpdate styling, auto format).
   - Dependencies:
     * @codetrix-studio/capacitor-google-auth
     * firebase/auth
     * @capacitor/core
     * src/utils/secureStorage.ts
   - Độc lập (Standalone): RẤT CAO (90%). Đây là module quý giá nhất để tích hợp Google

   - Tên file: src/utils/secureStorage.ts
   - Mục đích: Cung cấp API đọc/ghi dữ liệu an toàn nhất trên thiết bị di động:
     * Tầng 1: Android Keystore / EncryptedSharedPreferences (capacitor-secure-storage-plugin).
     * Tầng 2: Android Native SharedPreferences (@capacitor/preferences).
     * Tầng 3: Web LocalStorage (Fallback trên Web).
     * Đảm bảo KHÔNG BAO GIỜ bị mất dữ liệu đăng nhập, cài đặt hay token khi người dùng
       cài đặt file APK mới đè lên bản cũ.
   - Dependencies:
     * capacitor-secure-storage-plugin
     * @capacitor/preferences
     * @capacitor/core
   - Độc lập (Standalone): HOÀN TOÀN ĐỘC LẬP (100%). Có thể copy sang mọi dự án Capacitor!

3. Service: Firebase Cloud Firestore Đồng Bộ Thời Gian Thực (Real-time Cross-Device)

NHÓM D: BUILD / CI-CD WORKFLOWS & NATIVE MOBILE CONFIGS
================================================================================

1. Workflow: Tự Động Build APK & Tạo Bản Phát Hành GitHub (Auto Build & Release)
   - Tên file: .github/workflows/auto-release.yml
   - Mục đích:
     * Kích hoạt tự động mỗi khi đẩy mã nguồn lên nhánh `main` trên GitHub.
     * Tự động sinh versionName từ `package.json` và versionCode từ số commit Git.
     * Tự cấu hình JDK 21 (Zulu), Android SDK, Gradle Init Script (fix lỗi BouncyCastle).
     * Build web `npm run build`, đồng bộ Capacitor `npx cap sync android`.
     * Ký duyệt APK tự động bằng Keystore sẵn có.
     * Tự động tạo GitHub Release và đính kèm file APK (`sotietkiem_vX.X.X.apk`) để người

  [App.tsx khởi chạy]
         │
         ├──> 1. Đọc tức thì từ LocalStorage để render UI ngay (tránh màn hình trắng)
         │
         ├──> 2. Đặt cờ isSessionRestored = false (chặn ghi đè mặc định)
         │
         ├──> 3. Gọi restoreSessionFromPreferences() bất đồng bộ:
         │       ├── Đọc KeyStore phần cứng (SecureStorage) & SharedPreferences
         │       ├── Khôi phục cài đặt: Thông báo (notificationsEnabled), Khóa vân tay (enableBiometricLogin)
         │       ├── Khôi phục tài khoản người dùng (currentUser)
         │       └── Khôi phục Google OAuth Token & Refresh Token
         │
         ├──> 4. Kiểm tra khóa sinh trắc học:
         │       ├── Nếu enableBiometricLogin == true: Hiện BiometricUnlockModal yêu cầu quét vân tay / PIN
         │       └── Nếu không bật khóa vân tay: Tự động mở khóa (isUnlocked = true)
         │
         ├──> 5. Đặt isSessionRestored = true (bắt đầu cho phép ghi nhớ các thay đổi mới)
         │
         └──> 6. Kích hoạt hẹn giờ 2 giây: Gọi checkAppUpdate(false) kiểm tra phiên bản mới từ GitHub

3.2. Luồng Đồng Bộ Hai Chiều Google Drive & Sheets (Drive Sync Flow)
Ứng dụng sử dụng mô hình kết hợp giữa Google Drive và Cloud Firestore:

  [Người dùng tạo/sửa/xóa sổ hoặc bấm Đồng Bộ]
         │
         ├──> [useDriveSync hook]
         │       │
         │       ├──> Đẩy bản ghi Excel/JSON lên Google Drive của người dùng (Google Drive API)
         │       │    (Định dạng file: Sổ Tiết Kiệm Gia Đình - [Email].xlsx hoặc .json)
         │       │
         │       ├──> Cập nhật bảng dữ liệu thời gian thực lên Google Sheets (Google Sheets API)
         │       │    (Giúp người dùng mở xem trực tiếp trên ứng dụng Google Sheets)
         │       │
         │       └──> Ghi nhật ký đồng bộ (Sync Audit Log)
         │
         └──> [firebaseFirestoreService]
                 │
                 ├──> Cập nhật "Master Workspace Pointer" lên Firestore:
                 │    (Chứa link file active, thời gian đồng bộ mới nhất, danh sách thành viên)
                 │
                 └──> Các thiết bị khác của gia đình nhận được sự kiện onSnapshot
                      và tự động kéo dữ liệu mới nhất về máy!

3.3. Luồng Kiểm Tra Cập Nhật Độc Lập Không Phụ Thuộc Đăng Nhập
Để tránh trường hợp người dùng gặp lỗi đăng nhập ở bản cũ mà không thể cập nhật:
  - Component <AppUpdateModal> được render đồng thời ở cả ngoài màn hình LoginModal
    lẫn bên trong màn hình chính.
  - Ngay cả khi chưa đăng nhập, sau 2 giây ứng dụng vẫn fetch(`${UPDATE_SERVER_URL}?_t=${Date.now()}`).
  - Nếu phát hiện bản mới, modal cập nhật lập tức nổi lên trên cùng (z-index: 70)
    cho phép người dùng bấm "Cập nhật ngay" để tải và cài đặt APK ngay lập tức.
