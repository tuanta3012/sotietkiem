1. MÔ TẢ CHỨC NĂNG & MỤC ĐÍCH SỬ DỤNG
--------------------------------------------------------------------------------
- Kiến trúc điều phối hộp thoại tập trung (Modal Manager Pattern) & Hộp thoại xác nhận an toàn:
  + Tách biệt triệt để: Chuyển toàn bộ mã nguồn render hộp thoại, popup, dialog ra khỏi file giao diện chính (`App.tsx` hoặc `MainView.tsx`), giữ cho component chính ngắn gọn, dễ đọc, chỉ tập trung vào nghiệp vụ.
  + Hỗ trợ Lazy Loading (`React.lazy` + `<Suspense>`): Cho phép nạp các modal nặng (như bảng tính Excel, đồ thị tài chính, đồng bộ đám mây) chỉ khi người dùng bấm mở, giúp ứng dụng khởi động tức thì trên thiết bị di động yếu.
  + Hộp thoại xác nhận phá hủy an toàn (`DestructiveConfirmDialog`):
    * Thiết kế cảnh báo chuẩn UX (Màu đỏ/hồng nổi bật, icon cảnh báo, thông điệp rõ ràng).
    * Hiển thị số lượng dữ liệu sẽ bị xóa hoặc rủi ro gặp phải (ví dụ: mất dữ liệu chưa lưu, xóa vĩnh viễn tài khoản).
    * Hỗ trợ nút Hủy mặc định an toàn và hiệu ứng chạm rung phản hồi trên mobile.
  + Quản lý phân tầng hiển thị (Z-Index Scale Hierarchy):
    * Modal nghiệp vụ: `z-50`
    * Modal xác nhận / Cảnh báo đè: `z-[60]`
    * Modal cập nhật APK hệ thống / Khóa sinh trắc học: `z-[70]`
    * Chống hiện tượng click xuyên thấu (click bubbling) hoặc backdrop bị đen kịt khi mở modal lồng nhau.

```tsx
import React from 'react';
import { AlertTriangle, Trash2, X } from 'lucide-react';

export interface DestructiveConfirmDialogProps {
  isOpen: boolean;
  title?: string;
  description?: string;
  confirmLabel?: string;
  cancelLabel?: string;
  itemCount?: number;
  itemName?: string;
  dangerLevel?: 'warning' | 'danger';
  onConfirm: () => void;
  onClose: () => void;
}

export const DestructiveConfirmDialog: React.FC<DestructiveConfirmDialogProps> = ({
  isOpen,
  title = 'Xác Nhận Xóa Dữ Liệu?',
  description,
  confirmLabel = 'Xóa Vĩnh Viễn',
  cancelLabel = 'Hủy Bỏ',
  itemCount,
  itemName = 'bản ghi',
  dangerLevel = 'danger',
  onConfirm,
  onClose,
}) => {
  if (!isOpen) return null;

  const defaultDescription =
    itemCount !== undefined && itemCount > 0
      ? `Bạn có chắc chắn muốn xóa ${itemCount} ${itemName} này không? Thao tác này không thể hoàn tác.`
      : 'Bạn có chắc chắn muốn thực hiện hành động này không? Dữ liệu bị xóa sẽ không thể khôi phục.';

  const isCritical = dangerLevel === 'danger';

  return (
    <div className="fixed inset-0 z-[60] flex items-center justify-center p-4 bg-slate-950/75 backdrop-blur-xs animate-in fade-in duration-150">
      <div className="bg-white dark:bg-slate-900 w-full max-w-sm rounded-3xl shadow-2xl border border-slate-200 dark:border-slate-800 overflow-hidden flex flex-col animate-in zoom-in-95 duration-150">
        
        {/* Nút đóng góc trên */}
        <div className="p-3 pb-0 flex justify-end">
          <button
            type="button"
            onClick={onClose}
            className="p-1 rounded-full text-slate-400 hover:text-slate-600 dark:hover:text-slate-200 transition-colors"
          >
            <X className="w-4 h-4" />
          </button>
        </div>

        {/* Nội dung thông báo */}
        <div className="px-6 pb-6 text-center space-y-3">
          <div
            className={`w-14 h-14 rounded-2xl flex items-center justify-center mx-auto shadow-inner ${
              isCritical
                ? 'bg-rose-100 dark:bg-rose-950/50 text-rose-600 dark:text-rose-400'
                : 'bg-amber-100 dark:bg-amber-950/50 text-amber-600 dark:text-amber-400'
            }`}
          >
            {isCritical ? <Trash2 className="w-7 h-7" /> : <AlertTriangle className="w-7 h-7" />}
          </div>

          <div className="space-y-1.5">
            <h3 className="font-black text-lg text-slate-900 dark:text-white tracking-tight">
              {title}
            </h3>
            <p className="text-xs text-slate-500 dark:text-slate-400 leading-relaxed">
              {description || defaultDescription}
            </p>
          </div>
        </div>

        {/* Các nút hành động */}
        <div className="p-3 bg-slate-50 dark:bg-slate-950/50 border-t border-slate-100 dark:border-slate-800 grid grid-cols-2 gap-2.5">
          <button
            type="button"
            onClick={onClose}
            className="w-full py-2.5 rounded-xl bg-white dark:bg-slate-800 hover:bg-slate-100 dark:hover:bg-slate-700 text-slate-700 dark:text-slate-300 font-semibold text-xs border border-slate-200 dark:border-slate-700 transition-colors cursor-pointer"
          >
            {cancelLabel}
          </button>
          <button
            type="button"
            onClick={() => {
              onConfirm();
              onClose();
            }}
            className={`w-full py-2.5 rounded-xl font-bold text-xs shadow-md transition-all active:scale-[0.98] flex items-center justify-center gap-1.5 cursor-pointer text-white ${
              isCritical
                ? 'bg-rose-600 hover:bg-rose-700 shadow-rose-600/20'
                : 'bg-amber-600 hover:bg-amber-700 shadow-amber-600/20'
            }`}
          >
            {isCritical ? <Trash2 className="w-3.5 h-3.5" /> : <AlertTriangle className="w-3.5 h-3.5" />}
            <span>{confirmLabel}</span>
          </button>
        </div>

      </div>
    </div>
  );
};
```

File B: src/components/AppModalsContainer.tsx (Mẫu Kiến Trúc Quản Lý Tập Trung)
--------------------------------------------------
```tsx
import React, { Suspense } from 'react';
import { Loader2 } from 'lucide-react';
import { DestructiveConfirmDialog } from './DestructiveConfirmDialog';

// Mẫu lazy loading cho modal dung lượng lớn
const HeavyDetailModal = React.lazy(() =>
  import('./HeavyDetailModal').then((m) => ({ default: m.HeavyDetailModal }))
);

const ModalLoadingFallback = () => (
  <div className="fixed inset-0 z-50 flex items-center justify-center p-4 bg-slate-950/60 backdrop-blur-xs">
    <div className="bg-white dark:bg-slate-900 rounded-2xl shadow-xl p-5 flex flex-col items-center gap-3">
      <Loader2 className="w-6 h-6 animate-spin text-emerald-600" />
      <span className="text-xs font-semibold text-slate-700 dark:text-slate-300">Đang nạp dữ liệu...</span>
    </div>
  </div>
);

export interface AppModalsContainerProps {
  // Confirm wipe state
  isConfirmClearOpen: boolean;
  setIsConfirmClearOpen: (open: boolean) => void;
  onConfirmClearAll: () => void;
  itemsCount: number;

  // Detail Modal state
  isDetailOpen: boolean;
  setIsDetailOpen: (open: boolean) => void;
  activeItem: any;
}

export const AppModalsContainer: React.FC<AppModalsContainerProps> = ({
  isConfirmClearOpen,
  setIsConfirmClearOpen,
  onConfirmClearAll,
  itemsCount,
  isDetailOpen,
  setIsDetailOpen,
  activeItem,
}) => {
  return (
    <>
      {/* 1. Modal xác nhận xóa */}
      <DestructiveConfirmDialog
        isOpen={isConfirmClearOpen}
        title="Xóa Toàn Bộ Dữ Liệu?"
        itemCount={itemsCount}
        itemName="mục tiết kiệm"
        confirmLabel="Xóa Ngay"
        onConfirm={onConfirmClearAll}
        onClose={() => setIsConfirmClearOpen(false)}
      />

      {/* 2. Modal chi tiết nạp theo nhu cầu (Lazy Load) */}
      {isDetailOpen && (
        <Suspense fallback={<ModalLoadingFallback />}>
          <HeavyDetailModal
            isOpen={isDetailOpen}
            item={activeItem}
            onClose={() => setIsDetailOpen(false)}
          />
        </Suspense>
      )}
    </>
  );
};
```

4. HƯỚNG DẪN TÍCH HỢP VÀO APP MỚI TRONG 3 BƯỚC

Bước 1: Copy file `src/components/DestructiveConfirmDialog.tsx` vào dự án mới.

Bước 2: Sử dụng hộp thoại xác nhận khi người dùng bấm nút xóa nguy hiểm:
```tsx
import React, { useState } from 'react';
import { DestructiveConfirmDialog } from './components/DestructiveConfirmDialog';

export function ItemList() {
  const [showConfirm, setShowConfirm] = useState(false);

  const handleWipeData = () => {
    localStorage.clear();
    console.log('Đã dọn dẹp sạch dữ liệu!');
  };

  return (
    <div>
      <button
        onClick={() => setShowConfirm(true)}
        className="px-4 py-2 bg-rose-600 text-white rounded-xl text-xs font-bold"
      >
        Xóa Toàn Bộ Dữ Liệu
      </button>

      <DestructiveConfirmDialog
        isOpen={showConfirm}
        itemCount={12}
        itemName="giao dịch"
        onConfirm={handleWipeData}
        onClose={() => setShowConfirm(false)}
      />
    </div>
  );
}
```

Bước 3: Tách toàn bộ các modal ra component `AppModalsContainer.tsx` như mẫu trên và nhúng 1 dòng duy nhất vào cuối `App.tsx`:
```tsx
return (
  <div className="app-layout">
    <MainContent />
    <AppModalsContainer {...modalProps} />
  </div>
);
```
