1. MÔ TẢ CHỨC NĂNG & MỤC ĐÍCH SỬ DỤNG
--------------------------------------------------------------------------------
- Tự động hóa 100% quy trình sản xuất bộ nhận diện biểu tượng ứng dụng di động & web:
  + Chỉ cần 01 file ảnh gốc duy nhất (`master_icon.png` kích thước 1024x1024 hoặc 512x512).
  + Tự động sinh toàn bộ cây thư mục mipmap Android chuẩn Google Play:
    * `mipmap-mdpi`: 48x48
    * `mipmap-hdpi`: 72x72
    * `mipmap-xhdpi`: 96x96
    * `mipmap-xxhdpi`: 144x144
    * `mipmap-xxxhdpi`: 192x192
  + Tự động sinh Biểu tượng tròn Android (Round Icon `ic_launcher_round.png`): Cắt mặt nạ hình tròn mịn viền (Antialiased Circle Mask).
  + Tự động sinh Biểu tượng thích ứng Android 8+ (Adaptive Icons):
    * `ic_launcher_foreground.png`: Căn chỉnh logo vào vùng an toàn (Safe Zone 66% - 72%) để khi hệ điều hành Android bo tròn, bo góc vuông (squircle) hay hình giọt nước thì logo không bao giờ bị cắt cụt.
    * `mipmap-anydpi-v26/ic_launcher.xml` & `ic_launcher_round.xml`.
    * Cấu hình màu nền `values/colors.xml` (`ic_launcher_background`).
  + Tự động sinh bộ Web Favicon & PWA Icons:
    * `favicon-16x16.png`, `favicon-32x32.png`, `favicon.png` (64x64).
    * `apple-touch-icon.png` (180x180) cho iOS Safari Add to Home Screen.
    * `pwa-192x192.png` và `pwa-512x512.png` cho Progressive Web Apps.
  + Tự động sinh màn hình khởi động Splash Screen (`splash.png` 2732x2732) với màu nền đồng bộ thương hiệu và logo chính giữa.

```python
#!/usr/bin/env python3
"""
Automated App Icon & Splash Screen Asset Pipeline
Generates all Android mipmap densities, adaptive icons, web favicons & PWA icons.
"""

import os
import sys
from PIL import Image, ImageDraw

def create_circular_icon(image):
    """Tạo biểu tượng hình tròn hoàn hảo với alpha mask mịn viền"""
    size = image.size
    mask = Image.new('L', size, 0)
    draw = ImageDraw.Draw(mask)
    draw.ellipse((0, 0, size[0], size[1]), fill=255)
    
    output = Image.new('RGBA', size, (0, 0, 0, 0))
    output.paste(image, (0, 0))
    output.putalpha(mask)
    return output

def create_adaptive_foreground(image, target_size):
    """
    Tạo icon foreground thích ứng: Đặt logo vào trung tâm vùng an toàn (72% kích thước)
    """
    fg = Image.new('RGBA', (target_size, target_size), (0, 0, 0, 0))
    inner_size = int(target_size * 0.72)
    resized_logo = image.resize((inner_size, inner_size), Image.Resampling.LANCZOS)
    
    offset = (target_size - inner_size) // 2
    fg.paste(resized_logo, (offset, offset), resized_logo)
    return fg

def main():
    # 1. Đường dẫn file gốc
    src_path = sys.argv[1] if len(sys.argv) > 1 else 'resources/icon.png'
    bg_color_hex = sys.argv[2] if len(sys.argv) > 2 else '#06B46F' # Mã màu nền thương hiệu

    if not os.path.exists(src_path):
        print(f"❌ Không tìm thấy file icon gốc tại: {src_path}")
        print("Cách dùng: python generate_app_assets.py <path_to_master_icon.png> [hex_color]")
        sys.exit(1)

    print(f"🚀 Bắt đầu sinh bộ assets từ: {src_path} (Màu nền: {bg_color_hex})")
    master = Image.open(src_path).convert('RGBA')

    # Đảm bảo các thư mục đích tồn tại
    os.makedirs('public', exist_ok=True)
    os.makedirs('resources/android', exist_ok=True)
    android_res = 'android/app/src/main/res'
    os.makedirs(android_res, exist_ok=True)

    # 2. Sinh Web Favicon & PWA Assets
    print("📦 Đang sinh Web & PWA assets...")
    master.resize((16, 16), Image.Resampling.LANCZOS).save('public/favicon-16x16.png')
    master.resize((32, 32), Image.Resampling.LANCZOS).save('public/favicon-32x32.png')
    master.resize((64, 64), Image.Resampling.LANCZOS).save('public/favicon.png')
    master.resize((180, 180), Image.Resampling.LANCZOS).save('public/apple-touch-icon.png')
    master.resize((192, 192), Image.Resampling.LANCZOS).save('public/pwa-192x192.png')
    master.resize((512, 512), Image.Resampling.LANCZOS).save('public/pwa-512x512.png')

    # 3. Sinh Splash Screen (2732x2732)
    print("🎨 Đang sinh Splash Screen...")
    splash = Image.new('RGBA', (2732, 2732), '#0F172A') # Dark slate background
    splash_logo = master.resize((768, 768), Image.Resampling.LANCZOS)
    splash.paste(splash_logo, ((2732 - 768) // 2, (2732 - 768) // 2), splash_logo)
    splash.save('resources/splash.png')

    # 4. Sinh Mipmap Densities cho Android
    densities = {
        'mipmap-mdpi': (48, 108),
        'mipmap-hdpi': (72, 162),
        'mipmap-xhdpi': (96, 216),
        'mipmap-xxhdpi': (144, 324),
        'mipmap-xxxhdpi': (192, 432),
    }

    print("📱 Đang sinh Android Mipmap Icons & Adaptive Foregrounds...")
    for folder, (size, fg_size) in densities.items():
        dir_path = os.path.join(android_res, folder)
        os.makedirs(dir_path, exist_ok=True)

        # Standard launcher icon
        resized = master.resize((size, size), Image.Resampling.LANCZOS)
        resized.save(os.path.join(dir_path, 'ic_launcher.png'))

        # Round launcher icon
        round_icon = create_circular_icon(resized)
        round_icon.save(os.path.join(dir_path, 'ic_launcher_round.png'))

        # Adaptive foreground
        fg_icon = create_adaptive_foreground(master, fg_size)
        fg_icon.save(os.path.join(dir_path, 'ic_launcher_foreground.png'))

    # 5. Sinh cấu hình XML Adaptive Icons cho Android 8+ (v26)
    v26_dir = os.path.join(android_res, 'mipmap-anydpi-v26')
    os.makedirs(v26_dir, exist_ok=True)

    adaptive_xml = '''<?xml version="1.0" encoding="utf-8"?>
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@color/ic_launcher_background"/>
    <foreground android:drawable="@mipmap/ic_launcher_foreground"/>
</adaptive-icon>
'''
    with open(os.path.join(v26_dir, 'ic_launcher.xml'), 'w') as f:
        f.write(adaptive_xml)
    with open(os.path.join(v26_dir, 'ic_launcher_round.xml'), 'w') as f:
        f.write(adaptive_xml)

    # 6. Ghi màu nền vào values/colors.xml
    values_dir = os.path.join(android_res, 'values')
    os.makedirs(values_dir, exist_ok=True)
    colors_xml = f'''<?xml version="1.0" encoding="utf-8"?>
<resources>
    <color name="ic_launcher_background">{bg_color_hex}</color>
</resources>
'''
    with open(os.path.join(values_dir, 'colors.xml'), 'w') as f:
        f.write(colors_xml)

    print("✅ Hoàn tất 100%! Tất cả icon Android và Web đã được sinh ra chính xác.")

if __name__ == '__main__':
    main()
```

4. HƯỚNG DẪN TÍCH HỢP VÀO APP MỚI TRONG 3 BƯỚC
--------------------------------------------------------------------------------

Bước 1: Chuẩn bị 1 ảnh logo vuông (PNG chất lượng cao, tối thiểu 512x512 px) và lưu tại `resources/icon.png`.

Bước 2: Cài đặt thư viện Pillow:
```bash
pip install Pillow
```

Bước 3: Chạy script tự động tạo toàn bộ asset:
```bash
python scripts/generate_app_assets.py resources/icon.png #06B46F
```
- Script sẽ tự động điền đầy đủ mọi kích thước vào `android/app/src/main/res/` và `public/`.
- Khi build APK hoặc chạy `npm run build`, ứng dụng của bạn sẽ có icon sắc nét tuyệt đối trên mọi đời máy Android!
